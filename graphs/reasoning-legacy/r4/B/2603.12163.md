## Limitations and conditions

- "This setting is intentionally minimal" (line 41) — scope: two modes and an expressive model family.
- "Throughout this paper, we assume that the component $q_{\mathrm{o}}$ has already been trained to approximate the old
  distribution" (line 29) — assumption under every result.
- "We use a shared covariance $\Sigma$ (with bounded spectrum) for both modes so that separation and overlap are
  controlled purely by the means and the mixture weights." (line 167) — the equal-covariance assumption behind the
  exp(-δ²/8) rates.
- "To isolate the effect of learning the mixture weight, we further set $m_{\mathrm{o}}=\mu_{\mathrm{o}}$ and
  $m_{\mathrm{n}}=\mu_{\mathrm{n}}$ in the learner model and optimize only over $\beta$ ." (line 49) — condition on the
  mass-forgetting theorem.
- "Assume the old mean is already correct: $m_{\mathrm{o}}=\mu_{\mathrm{o}}$ (with $m_{\mathrm{n}}$ arbitrary)." (line
  311) — the drift bound is a gradient bound at the correct old mean.
- "when optimizing reverse-KL toward a target that explicitly retains the old mode" (line 323) — the reverse-KL
  retention result assumes the RL target already contains the old mode at weight α.
- "a local Polyak–Łojasiewicz (PL) analysis shows that, in sufficiently separated regimes, the reverse-KL objective
  exhibits a favorable local geometry" (line 61) — the exponential convergence is local and needs separation.
- "However, this population-level picture does not by itself rule out a purely stochastic failure mode." (line 371) —
  the population results do not cover finite batches; this motivates replay.
- "We show it is exponentially small under additional assumptions; see Remark 3.2." (line 91) — SDFT's drift is only
  finite in general; exponential smallness needs extra separation assumptions (lines 540-544).
- "Future work includes extending this analysis to high-dimensional generative models where behaviors correspond to
  richer semantic modes rather than mixture models." (line 764) — the results are not shown for real generative models.
